# Design System: Furniture Collections List
**Project ID:** 13534454087919359824

## 1. Visual Theme & Atmosphere

The interface feels like a sophisticated minimalist sanctuary with gallery-like spaciousness, photography-first presentation, and a calm editorial tone. It prioritizes breathing room, clear hierarchy, and a refined, quiet luxury sensibility.

## 2. Color Palette & Roles

- Warm Barely-There Cream (#FCFAFA) for the primary page canvas
- Crisp Very Light Gray (#F5F5F5) for secondary surfaces and cards
- Deep Muted Teal-Navy (#294056) for primary actions and active states
- Charcoal Near-Black (#2C2C2C) for headings and primary text
- Soft Warm Gray (#6B6B6B) for secondary text
- Ultra-Soft Silver Gray (#E0E0E0) for borders and dividers

## 3. Typography Rules

Use a modern geometric sans-serif with slight humanist warmth. Headlines are semi-bold with subtle tracking; body text is regular with generous line-height and relaxed spacing; metadata is smaller and visually recessive.

## 4. Component Stylings

* **Buttons:** Subtly rounded, deep muted teal-navy background, white text, smooth hover darkening, soft focus glow.
* **Cards/Containers:** Gently rounded corners, neutral surfaces, flat by default, whisper-soft shadow on hover.
* **Inputs/Forms:** Hairline border, neutral surface, subtly rounded corners, primary-color focus state.

## 5. Layout Principles

Use a responsive grid with generous section spacing, large margins, and image-led composition. Maintain strong whitespace, restrained UI chrome, and a top-to-bottom editorial reading flow.
